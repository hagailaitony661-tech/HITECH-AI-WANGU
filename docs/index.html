Deployment

Kuweka AI yako ipatikane kupitia mtandao.

Dashboard inaweza kuchapishwa kama tovuti tuli. Ili AI ifikiwe popote, backend na Ollama lazima ziwe kwenye seva inayopatikana mtandaoni. Kompyuta ya nyumbani ikizimwa au intaneti ikikatika, AI yako haitapatikana.

Muundo wa Hybrid

Dashboard (web) → FastAPI backend → Ollama model server. Tumia HTTPS na API key. Usifungue Ollama moja kwa moja kwenye intaneti; pitisha maombi kupitia backend iliyolindwa.
